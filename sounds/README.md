# 🎧 실제 녹음 소리 넣기 (선택)

기본 ASMR 소리는 파일 없이 브라우저에서 실시간 합성돼요.
직접 녹음했거나 **상업적 이용이 허락된(CC0 등) 소리**를 이 폴더에 넣으면 합성음 대신 그 파일이 재생돼요.
(유튜브 영상 소리는 저작권이 있어서 쓰면 안 돼요!)

1. 파일을 이 폴더에 넣고
2. `manifest.json` 에 파일 이름을 적어 주세요. 예: `["step-earpick1.mp3", "bgm-rain.mp3"]`
