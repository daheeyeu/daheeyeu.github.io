# 🫧 뽀득뽀득 뷰티샵

도트 게임 느낌의 ASMR 대리만족 뷰티샵 사이트예요.
잔털 면도 · 왁싱 · 귀청소 · 마사지 · 팩 · 폼클렌징 · 헤드스파 · 간식바 방에 들어가서
제품을 **써보기**(애니메이션 + ASMR 효과음) 하고, 성분·재질·리뷰를 보고, 장바구니에 담거나 바로 구매할 수 있어요.

## 내용 고치기
모든 상품/방/제휴 링크는 `js/data.js` 한 파일에 있어요.

- **제휴 링크**: 각 상품의 `link: ""` 에 내 링크를 넣으면 [구매] 버튼이 그 링크로 연결돼요. 비워 두면 해당 스토어 검색 결과로 연결됩니다.
- **스토어**: `store` 를 `oliveyoung` / `daiso` / `coupang` 중 하나로.
- **성분·재질·리뷰**: `ingredients`, `material`, `reviews` (기본 리뷰는 예시 문구라 실제 후기로 바꿔 주세요).
- **제휴 고지 문구**: `SITE.disclosure`.

## 파일 구조
```
index.html
css/style.css
js/data.js     ← 상품·방·링크 데이터 (여기만 고치면 됨)
js/sprites.js  ← 도트 캐릭터
js/asmr.js     ← Web Audio로 만든 ASMR 효과음
js/app.js      ← 화면 로직
```

## 참고
장바구니·리뷰·추천 투표는 방문자 각자의 브라우저(localStorage)에 저장돼요.
다른 사람들과 투표를 공유하려면 Supabase/Firebase 같은 백엔드를 붙여야 해요.
